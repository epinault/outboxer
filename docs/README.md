# Project notes

This directory is the project's memory. It is committed on purpose, so the knowledge survives a
lost machine and is available from any clone. Add to it rather than to tool-local storage.

| File | What it holds |
| --- | --- |
| [constraints.md](constraints.md) | Invariants and gotchas the code depends on. Read before changing the delivery path or storage |
| [backlog.md](backlog.md) | Known gaps and deferred work, with the reason for each deferral |
| [build-log.md](build-log.md) | What was built when, and what went wrong along the way |
| [superpowers/specs/](superpowers/specs/) | The original design document |

User-facing documentation is in [`../guides`](../guides) and ships with the Hex package.
